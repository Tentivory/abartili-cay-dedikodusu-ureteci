# Abartılı Çay Dedikodusu Üreteci

Bu repository, Türk milletinin en kutsal sıvısı olan çayın etrafında dönen dedikoduları bilimsel olarak üreten devrim niteliğinde bir projedir.

## Neden Bu Proje?

Çünkü çay demlenmezse dünya dönmez. Dedikodu olmazsa çay soğur. Bu ikisi birbirine bağlıdır, Einstein de söylemiştir (belki).

## Nasıl Kullanılır?

```bash
python cay_dedikodusu.py
```

Ve izleyin nasıl tarih yazılıyor.

## Uyarı

Bu programı çalıştırmadan önce çay demleyin. Yoksa program küsüp çalışmaz.
